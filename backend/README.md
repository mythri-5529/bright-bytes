# Bright Bytes Backend

This directory contains the Python Flask backend for Bright Bytes.

## Overview

The backend provides RESTful API endpoints for the Bright Bytes application.

## API Endpoints

- `GET /api/health` - Health check
- `GET /api/data` - Retrieve data
- `POST /api/data` - Create new data

See main README for detailed API documentation.
